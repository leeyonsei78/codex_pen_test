연결 정보 처리

이 화면은 ARTEX의 모델 조회·테스트·저장 API와 실제로 연결됩니다. API 키를 브라우저 저장소·경량 보고서·로컬 설정 파일에 저장하지 않습니다. 저장 버튼을 누르면 키가 ARTEX 데이터베이스에 보관됩니다. API 테스트는 공급자에게 요청을 보내며 비용이 발생할 수 있습니다.

브라우저 탭 종료만으로 관리자 연결이 해제되지는 않습니다. 사용 후 연결 해제를 누르세요. 이 화면에서는 점검 작업을 시작하거나 서버를 수정하지 않습니다. 자동 탐지 결과 승인·수정 적용·재점검의 통합 개발은 별도입니다.
