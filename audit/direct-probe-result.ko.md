# 허가 URL 소량 능동 점검 결과

점검일: 2026-10-30 KST

대상: https://direct.e-lina.co.kr/emall/P00303.htm?t=S1_2106_A_01

사용자가 점검 권한을 확인하고 제공한 단일 URL에 정상 GET 1회, 추가 쿼리 `audit_probe=AUDIT_SAFE_20261030_Q7`를 붙인 GET 1회만 전송했다. 요청 사이 1.2초 간격, 인증정보 없음, 리다이렉트 추적 없음, 응답당 1 MiB/요청당 15초 제한이다. 스크립트·HTML 공격 구문은 전송하지 않았다.

## 관측 결과

| 항목 | 결과 | 해석 |
|---|---|---|
| 정상/표식 요청 상태 | 모두 HTTP 200 | 두 GET 처리 성공. WAF 탐지·차단 능력 평가를 의미하지 않음 |
| 응답 본문 | 둘 다 122,209바이트, SHA-256 동일 | 이번 추가 쿼리는 저장한 응답 본문을 바꾸지 않음 |
| 표식 반사 | 본문에서 미검출 | 이 파라미터/표식의 서버 응답 반사를 관측하지 못함. 기존 `t` 파라미터·브라우저 DOM·저장형 XSS는 미검증 |
| X-Frame-Options | DENY | 이 응답에 프레임 삽입 제한 헤더 있음 |
| Strict-Transport-Security | max-age=31536000; includeSubDomains | 이 HTTPS 응답에 HSTS 헤더 있음. 전체 도메인 TLS 구성 점검은 아님 |
| X-Content-Type-Options | nosniff | 해당 헤더 있음 |
| CSP / CSP Report-Only | 응답 헤더에서 미관측 | 추가 방어 설정 검토 대상. 헤더 부재만으로 XSS 취약점을 입증하지 않음. HTML meta 정책 유무는 별도 검토 필요 |

**이번 요청으로 악용 가능한 취약점이나 공격 차단 성공을 확정하지 않았다.** 인증 우회, 고객정보 조회, 계약 변경, SQL 주입, 내부망 요청, 다량 호출 및 실제 AI 입력 시험은 수행하지 않았다. HTML의 AI 관련 단어 검색만으로 AI 존재/부재를 판정하지 않는다.

기존 `www.lina.co.kr` 증적의 결론을 이 `direct.e-lina.co.kr`에 그대로 적용할 수 없다. 특히 이 응답에는 기존 www 점검과 달리 `X-Frame-Options: DENY`가 존재한다.

## 증적 및 다음 검증

- 요청·응답 메타데이터: [results.json](direct-probe-evidence/2026-10-30T10-18-40-090Z/results.json)
- 원본 본문: 같은 폴더의 `baseline.html`, `marker.html`
- 실행 코드: `probe-authorized-direct.mjs`. 재실행하면 실제 요청 최대 2회가 다시 발생한다.

추가 능동 시험 전에는 허용 파라미터·공격 유형·요청 한도를 구체화한다. AI 기능 시험에는 실제 챗봇 입력 경로, LLM 사용 여부 및 합성 데이터가 있는 테스트 환경이 필요하다. 서버의 권한·토큰 회수는 별도 테스트 계정으로 검사해야 한다. 이번에는 이 URL 외 추가 자원이나 API를 요청하지 않았다.

## 후속: 실제 XSS 구문 소량 전송

사용자가 실제 공격 구문 시험을 추가 요청하여 같은 URL에 GET 최대 2회를 수행했다. SVG의 onload 이벤트에서 합성 표식을 `console.info`로 출력하는 XSS 시험 구문을 URL 인코딩해 전송했다. 쿠키/저장소 읽기, 외부 전송, 데이터 변경 코드는 포함하지 않았다. 브라우저로 응답을 실행하지 않았다.

| 파라미터 | 응답 | 관측 |
|---|---|---|
| 추가 `audit_probe` | 200 | 본문 해시가 정상 응답과 동일. 원문 구문과 표식 모두 미반사 |
| 기존 `t` 값 뒤에 구문 추가 | 404 | 비정상 상태를 받아 시험 중단. 리다이렉트·재시도·우회 없음 |

404의 원인이 라우팅인지 입력 검증인지 WAF인지 확인하지 못했다. 차단 성공으로 판정하지 않는다. 서버 응답 반사와 실제 브라우저 DOM 실행은 다른 검증이므로 XSS 부재로 판정하지 않는다. 이 회차에서도 AI 엔드포인트를 확인하지 못해 AI 입력은 전송하지 않았다.
