# 라이나생명 공개 주소 기초 보안 점검 결과

점검일: 2026-10-30 (KST)

## 결론

확정 취약점 없음. 이는 안전 판정이 아니라 검증 한계에 따른 판정 보류이다. 문서의 8개 호스트 대표 주소와 23개 세부 URL에 HEAD 요청을 각 1회 시도했으나, 모든 요청이 로컬 Schannel 자격 증명 오류 SEC_E_NO_CREDENTIALS로 실패했다. HTTP 000은 서버가 반환한 상태 코드가 아니다. 인증서 검증 결과 0도 이 상황에서 인증서 정상의 증거로 해석하면 안 된다.

원문에는 전체가 미사용 사이트라는 뜻은 아니라고 명시되어 있다. 운영 종료 여부는 미확정이다.

## 수행 범위와 한계

문서에 기재된 31개 HTTPS URL에만 HEAD 요청을 시도했다. 리디렉션은 따라가지 않았다. 별도 웹 조회로 9개 URL의 공개 텍스트 자료를 확인했으며, 일부 자료는 과거 크롤링 결과이다. 로그인, 입력값 제출, SSO 토큰 발급, API 호출, 취약점 공격 재현, 설치 파일 실행은 수행하지 않았다. TLS 설정, 보안 헤더, 쿠키 속성, 인증 및 권한 검증은 이번 환경에서 판정하지 못했다.

웹 조회는 현재 원본 서버의 실시간 응답·헤더를 보증하지 않는다. 아래 시점은 도구가 표시한 크롤링 시점이다.

- [VeraPort 설치 안내](https://ga.lina.co.kr/wizvera/veraport/install20/install_lina.html): 2일 전 수집 자료.
- [CrossWebEX 설치 안내](https://ga.lina.co.kr/gap/serviceEndpoint/initech/extension/install/install.html): 지난달 수집 자료.
- [전자구매 로그인](https://srm.lina.co.kr/login.do): 지난달 수집 자료. IP 접근 제한 안내.
- 공식·모바일 대표 주소 및 건강검진 경로는 읽을 수 있는 본문을 확보하지 못함.

## 다음 점검에서 필요한 확인

정상 HTTPS 통신이 가능한 점검 환경에서 동일 URL의 응답 코드·리디렉션·인증서·보안 헤더를 재수집한다. 자산 담당자가 운영·폐기 이력과 접근 로그를 대조해 운영 여부를 확정한다. 테스트 경로의 기능 및 업무 API 접근통제 확인은 시스템 소유자가 승인한 대상·계정·방법·시간 범위 안에서 수행한다. 종료된 이벤트와 공개 PDF 자체는 취약점으로 분류하지 않는다.
